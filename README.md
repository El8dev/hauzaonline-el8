# حوزة أم البنين (ع) - منصة الاختبارات وإدارة الطلاب (MZMZ App)

منصة تعليمية متكاملة لإدارة الامتحانات الالكترونية، متابعة الحضور والغياب، وإدارة تسجيل واعتماد الطلاب.

## الميزات الرئيسية

- **إدارة هيكلية المراحل والترقية**: إمكانية ترتيب المراحل الدراسية بطريقة السحب والإفلات، وترقية الطلاب الناجحين للمرحلة التالية بضغطة زر.
- **امتحانات الدور الثاني**: دعم إنشاء امتحانات دور ثاني (Retake) والتي تظهر تلقائياً للطلاب الذين لم يجتازوا حاجز الـ 50 درجة في المجموع الكلي (نصف السنة + النهائي).
- **نظام التقييم والدرجات (50 + 50 = 100)**: احتساب درجة امتحان نصف السنة (50) والامتحان النهائي (50) وجمعهما مباشرة للحصول على النتيجة الكلية من 100 في السجل والشهادات والتقارير المطبوعة.
- **منع تكرار الامتحانات**: حماية تمنع المشرف من إنشاء أكثر من امتحان نهائي أو نصف سنة أو دور ثاني لنفس المادة والمرحلة والشعبة عن طريق الخطأ.
- **حماية تكرار أداء الامتحان**: عند فتح رابط امتحان قام الطالب بأدائه مسبقاً، تظهر شاشة تنبيه خاصة تعرض درجاته السابقة مع منع إعادة التقديم.
- **نظام التوجيه والمسارات (Client-Side Hash Router)**: دعم التنقل الكامل عبر أزرار الرجوع والتقدم في المتصفح (Back 🔙 / Forward 🔜)، والحفاظ على الشاشة الحالية عند إعادة تحميل الصفحة (`F5`).
- **نظام الإشعارات الحديث (In-App Toast & Hybrid Modal)**: استبدال تنبيهات المتصفح التقليدية بتنبيهات عائمة (Toasts) ونوافذ تفاعلية منسقة تدعم النسخ المباشر بضغطة زر.
- **إدارة الطلاب وتعيين الرقم الحوزوي**: تقديم طلبات التحاق، الاعتماد الإداري، والتوزيع على المراحل والشعب.
- **منصة إنشاء وإنتاج الامتحانات**: خيارات اختبارات متنوعة (كويز، نصف سنة، نهائي، دور ثاني) مع ربط مباشر وقابل للمشاركة.
- **متابعة الحضور والغياب**: سجل يومي مرن مع تخصيص أيام وأوقات الدوام.

## الإعداد والتشغيل

1. **تثبيت التبعيات**:
   ```bash
   npm install
   ```

2. **التشغيل المحلي**:
   ```bash
   npm run dev
   ```

3. **البناء للإنتاج**:
   ```bash
   npm run build
   ```
